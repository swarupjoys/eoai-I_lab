# Elements of AI – I: Lab Notebooks

This repository contains guided Google Colab notebooks for the *Elements of AI – I* course, designed for undergraduate students to learn basic AI concepts through hands-on activities.

## Contents
- Ready-to-use Colab notebooks (with preloaded code and instructions)
- Real-world educational datasets
- Regression, classification, and basic ML workflows
- Templates for experimentation and student reflection

## Target Audience
Students enrolled in *Elements of AI – I*, instructors, and self-learners looking for beginner-friendly, no-installation AI experiments using Python and Google Colab.

1. Visit any notebook link (shared by instructor or from this repo)
2. Click **"Open in Colab"** or use this format:

3. Run cells one-by-one and follow in-notebook instructions
4. Save a copy to your Google Drive to submit or modify
